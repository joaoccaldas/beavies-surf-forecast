# Beavies Surf Forecast

**Baltic Sea surf conditions and forecasting.** Real-time wave conditions, weather data, and predictive analytics to help surfers in the Baltic region decide when and where to paddle out.

## Features

### Live data feed
- Real-time surf conditions from multiple sources
- Wave height, period, and direction
- Wind speed, direction, and gusts

### Forecasting model
- Multi-day surf forecast with hourly granularity
- Weather-driven, ML-assisted wave condition predictions

## Technology

Python backend with real-time data processing. Deployed with the backend on Render and the frontend on GitHub Pages.

## Status

Active — used to plan personal surf trips on the Baltic.
