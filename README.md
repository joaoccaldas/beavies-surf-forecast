# Beavies Surf Forecast

## Overview

Beavies Surf Forecast is a comprehensive surf forecasting application specifically designed for the Baltic Sea region. This application provides real-time surf conditions, weather data, and predictive analytics to help surfers and water sports enthusiasts make informed decisions about when and where to catch the best waves.

## Key Features

### 🌊 Live Data Feed
- Real-time surf conditions from multiple data sources
- Wave height, period, and direction monitoring
- Wind speed, direction, and gust information
- Water and air temperature tracking

### 🔮 Forecasting Model
- Advanced weather prediction algorithms
- Multi-day surf forecast with hourly granularity
- Machine learning-powered wave condition predictions
- Optimized specifically for Baltic Sea wave patterns

### 📊 Interactive Visualization
- Dynamic charts and graphs for wave and wind conditions
- Geographic visualization of surf spots
- Historical data comparison
- Customizable dashboard views

### ⭐ User Input & Ranking System
- User-contributed surf spot ratings
- Community feedback and conditions reporting
- Personalized spot recommendations
- Ranking algorithm based on current conditions and user preferences

## Baltic Sea Focus

The Baltic Sea presents unique surfing conditions compared to ocean coastlines:
- Shallow water depth affecting wave formation
- Limited fetch resulting in shorter wave periods
- Strong influence of wind direction on surf quality
- Seasonal variations in surf conditions
- Multiple countries and diverse surf spots (Germany, Poland, Sweden, Denmark, etc.)

This application is specifically calibrated to understand and predict these unique Baltic Sea characteristics.

## Technology Stack

- **Backend**: Python-based API with real-time data processing
- **Frontend**: Interactive web interface with responsive design
- **Data Sources**: Multiple weather and oceanographic APIs
- **Deployment**: Render (backend), GitHub Pages (frontend)
